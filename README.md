A one-liner for the "The Houseplant Out-of-Office" bounty: the houseplant goes on leave, force-pushes the watering schedule to never, and leaves the cactus as the only one still clocking in. The joke follows the rule → violation → restore shape, with a technical verb applied to a very human (very plant) situation. The entry is a tiny stdlib-only Python program that writes the line to the output file the grader reads.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
